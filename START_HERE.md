Open this folder in Cursor (or VS Code) with the **Roo Code** extension. Roo Code instructions are under `.roo/`; they are not Cursor `.cursor/` rules.

- `.roo/rules/project.mdc`: repository-wide Roo Code rules.
- `.roo/skills/SKILL.md`: reusable development workflow.
